Below is a Replit-ready Epic & Task breakdown for Option A (DSA / Sub-DSA multi-financier loan routing), written so your engineering team can paste directly into Replit / Linear / Jira and start execution.
This scope assumes:
Fintekpro is Sub-DSA initially
Multi-bank routing for ICICI Bank, HDFC Bank, Axis Bank, Kotak Mahindra Bank
No paid LOS
Full RBI-compliant audit trail
EPIC 1 — Loan Origination Core (LOS – Free / Owned)
Goal
Capture, store, and manage loan applications independently of any bank.
Tasks
Design Loan Application Schema
Applicant profile (individual / business)
Income details (salaried / self-employed)
Loan product type
Requested amount & tenure
Build POST /loan/apply API
Build GET /loan/{id} API
Implement draft → submitted → routed → bank_decision state machine
Add document upload service
Aadhaar, PAN, income proof, bank statement
Implement consent capture (timestamp + IP + version)
Deliverable:
Standalone LOS service with REST APIs
EPIC 2 — Credit & Eligibility Engine
Goal
Decide which banks a loan should go to.
Tasks
Integrate Credit Bureau mock / sandbox
Normalize bureau response into internal score model
Build Eligibility Rules Engine
Income type
Credit score
Loan size
Create Bank Product Matrix
Bank × Loan Type × Eligibility
Build POST /loan/eligibility API
Store eligible banks list per application
Deliverable:
Deterministic bank shortlist per loan
EPIC 3 — Multi-Financier Routing Engine (Core IP)
Goal
Route one application to multiple financiers intelligently.
Tasks
Design routing strategies
Parallel (send to all)
Waterfall (Bank A → B → C)
Implement routing priority config
Build POST /route/loan/{loanId}
Generate bank-specific payload adapters
Store routing metadata (who, when, status)
Deliverable:
Bank-agnostic routing engine
EPIC 4 — Bank Connector Layer (DSA Rails)
Goal
Abstract how banks receive applications.
Tasks
Define internal submission interface
submit(bank_code, loan_payload)
Build connector stubs for:
ICICI (API / portal)
HDFC (SFTP / portal)
Axis (API)
Kotak (portal / batch)
Support:
API push
File export (CSV / XML)
Implement retry + failure handling
Deliverable:
One interface, many banks
EPIC 5 — Status Tracking & Webhooks
Goal
Give real-time visibility of bank decisions.
Tasks
Create bank status normalization
RECEIVED
IN_REVIEW
APPROVED
REJECTED
DISBURSED
Build GET /loan/{id}/status
Implement manual status update UI (portal fallback)
Add webhook listener framework
Store full decision history
Deliverable:
Single truth of loan status across banks
EPIC 6 — Compliance, Audit & RBI Safety
Goal
Be regulator-proof from day one.
Tasks
Implement audit log service
Who accessed what, when
Encrypt PII at rest
Mask sensitive fields in logs
Add bank disclosure statement per application
Generate downloadable audit report (PDF)
Deliverable:
RBI-aligned compliance layer
EPIC 7 — Admin & Ops Dashboard
Goal
Operate the system at scale.
Tasks
Loan funnel dashboard
Bank-wise conversion metrics
Manual override for routing
Failed submission re-push
Commission tracking placeholder
Deliverable:
Internal ops console
EPIC 8 — Client-Facing Experience
Goal
Transparent multi-bank experience for customers.
Tasks
Loan application UI
“Applied to X banks” view
Status timeline (bank-wise)
Secure document upload UI
Consent & disclosures screen
Deliverable:
Client-ready loan journey
