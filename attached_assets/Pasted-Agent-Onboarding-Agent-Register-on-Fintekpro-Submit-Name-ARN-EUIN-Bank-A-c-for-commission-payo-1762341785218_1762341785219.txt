Agent Onboarding
Agent → Register on Fintekpro
Submit: Name, ARN, EUIN, Bank A/c for commission payout
Fintekpro → Verify ARN/EUIN via AMFI API or manual validation
Store: agent_id, arn, euin, payout_account
2️⃣ Client Onboarding + Agent Mapping
Option A (Recommended): Client selects/refers from agent link
Agent shares referral link: fintekpro.com/signup?agent_id=AG123
Client signs up → system auto-links agent_id with client
Option B: Internal assignment by admin
Admin assigns agent → client_id.agent_id = AG123
✅ Store mapping:
client.agent_id = AG123
3️⃣ During MF / PMS / Insurance Transactions
When submitting to BSE STAR MF:
OrderEntryParam API fields:
ARN = agent.arn
EUIN = agent.euin
EmployeeCode / SubBroker Code = agent_id (optional internal field)
✅ This ensures AMC commission flows back to your ARN broker entity.
4️⃣ Payment Flow Clarification
Client → AMC (not agent)
Money always flows like this:
Client Bank → AMC Pool A/c / Payment Gateway → NAV allocated.
Agents never receive money directly.
They only receive:
Brokerage / Trail commissions → paid monthly by AMC/RTA.
5️⃣ Commission Calculation & Reporting
You will receive Commission Reports from:
Source	Format	Contains
RTA / CAMS / KFin	CSV/XML	Trail %, Brokerage, Folio, ARN
BSE STAR MF	Daily order/confirmation files	For verification
Fintekpro Commission Engine:
(Units * NAV * Trail Rate) → Calculate commission earned
Group commissions by agent_id
Store in commission table
