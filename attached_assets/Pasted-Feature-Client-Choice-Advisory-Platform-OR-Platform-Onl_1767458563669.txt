Feature: Client Choice — Advisory + Platform OR Platform-Only
1. Feature Objective (Do Not Interpret)

Implement a system where each client explicitly chooses one of the following modes for Global Investments:

Advisory + Platform

Platform-Only (Execution-Only)

The selected mode must:

Control UI visibility

Control AI availability

Control fee calculation

Control invoicing (Zoho Books)

Be auditable and regulator-safe (Securities and Exchange Board of India)

No implicit defaults. No silent switching.

Platform fee only
