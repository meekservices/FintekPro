EPIC: Benchmark-Aware Mutual Fund Metrics Engine
Goal
Enable accurate calculation of Alpha, Beta, Treynor Ratio, and Information Ratio by introducing benchmark (NIFTY) data ingestion, mapping, computation, and UI handling.
BACKEND TICKETS
BE-01: Create Market Index Master Tables
Type: Backend – Database
Priority: P0
Description
Introduce tables to store benchmark indices (NIFTY, Sensex) and their daily values.
Tasks
Create table market_indices
Create table market_index_nav
Add migration scripts
Schema
CREATE TABLE market_indices (
  id UUID PRIMARY KEY,
  index_code VARCHAR(20) UNIQUE NOT NULL,
  index_name VARCHAR(100),
  provider VARCHAR(20),
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE market_index_nav (
  id UUID PRIMARY KEY,
  index_id UUID REFERENCES market_indices(id),
  nav_date DATE NOT NULL,
  close_value NUMERIC(12,4),
  daily_return NUMERIC(10,6),
  UNIQUE(index_id, nav_date)
);
Acceptance Criteria
Tables created successfully
Index codes like NIFTY50, NIFTY500 supported
Unique constraint enforced
BE-02: Benchmark Ingestion Job (NIFTY)
Type: Backend – Cron / Worker
Priority: P0
Description
Daily ingestion of benchmark index closing values and return calculation.
Tasks
Create cron job syncMarketIndices()
Fetch historical + daily close prices
Compute daily returns
Upsert into market_index_nav
Notes
Store close value only
Calculate daily return as:
(today_close - yesterday_close) / yesterday_close
Acceptance Criteria
Daily data available for last 5+ years
No duplicate rows
Job is idempotent
BE-03: Mutual Fund ↔ Benchmark Mapping Table
Type: Backend – Database
Priority: P0
Description
Map mutual funds to benchmarks with confidence scoring.
Schema
CREATE TABLE mf_benchmark_map (
  id UUID PRIMARY KEY,
  mf_isin VARCHAR(20),
  index_code VARCHAR(20),
  confidence_score NUMERIC(3,2),
  source VARCHAR(30),
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(mf_isin)
);
Default Mapping Rules
Large Cap → NIFTY50
Mid Cap → NIFTY MIDCAP 150
Small Cap → NIFTY SMALLCAP 250
Flexi / Multi → NIFTY 500
Acceptance Criteria
One benchmark per ISIN
Confidence score stored
Admin override supported
