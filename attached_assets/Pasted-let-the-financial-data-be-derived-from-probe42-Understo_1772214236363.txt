2️⃣ Database Expansion for Financial Versioning
🔹 Financial Statements Table (Append-Only)
CREATE TABLE unlisted_financials (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    unlisted_equity_id UUID REFERENCES unlisted_equity_master(id),
    financial_year VARCHAR(10),
    revenue NUMERIC,

4️⃣ Financial Data Usage in Risk Engine
Now that Probe42 provides structured financials, we can enhance modeling.
📐 Enhanced Risk Model for Unlisted Assets
Instead of static haircut only, derive risk from financial ratios.
Let:

ROE = PAT / Net Worth
Leverage = Debt / Net Worth
Revenue Growth = CAGR(Revenue)
Step 1 — Financial Health Score (FHS)
Normalize:
FHS = w1*(ROE_zscore)
    + w2*(RevenueGrowth_zscore)
    - w3*(Leverage_zscore)
Scale FHS between 0 and 1.
Step 2 — Convert to Volatility Proxy
σ_unlisted = BaseSectorVol × (1 + RiskMultiplier)
Where:
RiskMultiplier = (1 - FHS)
So weaker financials → higher volatility proxy.
Step 3 — Liquidity Adjustment
Still apply:
LiquidityPenalty = λ × w_unlisted²
This preserves illiquidity premium.
