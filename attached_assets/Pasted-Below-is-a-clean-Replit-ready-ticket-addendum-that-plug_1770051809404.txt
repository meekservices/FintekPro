EPIC ADD-ON: AMFI Benchmark Auto-Parser & Auto-Mapping
Objective
Automatically extract scheme-level benchmark indices from AMFI data, normalize them, and map mutual funds to the most accurate benchmark with auditable confidence scoring.
BACKEND TICKETS (AMFI)
BE-09: AMFI Benchmark Data Ingestion
Type: Backend – Data Ingestion
Priority: P0
Description
Fetch and store scheme benchmark information published by AMFI.
Source
AMFI scheme master file
(fields include Scheme Name, Category, Benchmark Index)
Tasks
Create scheduled job syncAmfiSchemeBenchmarks()
Download latest AMFI scheme master
Parse:
ISIN
Scheme Name
Scheme Category
Benchmark Index (raw string)
Store raw benchmark text
New Table
CREATE TABLE amfi_scheme_benchmarks (
  id UUID PRIMARY KEY,
  mf_isin VARCHAR(20) UNIQUE,
  scheme_name TEXT,
  scheme_category VARCHAR(100),
  raw_benchmark TEXT,
  parsed_at TIMESTAMP DEFAULT NOW()
);
Acceptance Criteria
One row per ISIN
Raw benchmark text preserved verbatim
Job is idempotent
BE-10: Benchmark Normalization Engine
Type: Backend – Analytics Utility
Priority: P0
Description
Normalize messy AMFI benchmark strings into canonical index codes.
Examples
Raw AMFI Text	Normalized
NIFTY 50 TRI	NIFTY50
NIFTY 100 Total Return Index	NIFTY100
BSE SENSEX TRI	SENSEX
NIFTY 500 TRI	NIFTY500
Tasks
Create normalizeBenchmark(rawText)
Use regex + keyword mapping
Reject ambiguous strings (return NULL)
Acceptance Criteria
≥90% normalization success
No false-positive mappings
BE-11: Auto-Populate MF ↔ Benchmark Mapping from AMFI
Type: Backend – Business Logic
Priority: P0
Description
Auto-create benchmark mappings using AMFI data.
Logic
IF normalized benchmark exists
  → insert into mf_benchmark_map
  → source = 'AMFI'
  → confidence_score = 0.95
ELSE
  → fallback to category-based mapping
Rules
AMFI mapping overrides category defaults
Manual admin override always wins
Acceptance Criteria
AMFI mappings appear automatically
Confidence score correctly assigned
No overwrite of manual mappings
BE-12: Benchmark Confidence Scoring Engine
Type: Backend – Analytics
Priority: P1
Confidence Matrix
Source	Score
AMFI explicit benchmark	0.95
Category default	0.70
Manual admin override	1.00
Tasks
Centralize confidence calculation
Store score in mf_benchmark_map
Expose score to UI
Acceptance Criteria
Scores consistent across system
Used in metric availability flags
BE-13: Auto-Recompute Trigger on AMFI Update
Type: Backend – Workflow
Priority: P0
Description
Recompute metrics automatically when AMFI benchmark mapping changes.
Trigger
New AMFI benchmark detected
Normalized benchmark differs from existing mapping
Action
Update mf_benchmark_map
Trigger metrics recompute for affected ISINs only
Acceptance Criteria
No full recompute required
Only impacted funds recalculated

BE-14: AMFI Drift Monitor
Description
Detect when AMFI changes benchmark for a scheme.
Action
Log historical changes
Alert admin
Table
CREATE TABLE mf_benchmark_history (
  id UUID PRIMARY KEY,
  mf_isin VARCHAR(20),
  old_index_code VARCHAR(20),
  new_index_code VARCHAR(20),
  changed_at TIMESTAMP DEFAULT NOW()
);
