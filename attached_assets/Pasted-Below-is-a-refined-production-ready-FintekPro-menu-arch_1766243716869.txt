PART 4 — IMPLEMENTATION INSTRUCTIONS FOR REPLIT
(ENGINEERING TASK BLUEPRINT)
Navigation Architecture
• Create a single config-driven menu JSON supporting role-based visibility.
• Each item tagged with: id, label, icon, permission, feature-flag, route.
Role-Based Access Control (RBAC)
Tables required:
• users
• roles (client, agent, admin, premium)
• user_roles (mapping)
• permissions (view_invest, execute_trade, create_proposal, etc.)
Portfolio Engine Implementation
• Build microservice: portfolio-service
• Endpoints:
 GET /portfolio/pan/:pan
 GET /portfolio/assets
 POST /portfolio/external
• Integrate with depository & MF APIs.
AI Proposal Engine
• Inputs: client risk score, current portfolio, goals, product catalogue.
• Outputs: suggested buy/sell, rebalancing, priority actions, reasons.
• Store version history: proposals table.
Store Architecture
• Product catalog service with product_type field.
• Dynamic pages read from product metadata.
• AIF/PMS access controlled by premium flag.
MLD Engine
• Term sheet parser (PDF → JSON)
• Scenario simulator (yield curve, market conditions)
• Issuer feed ingestion
• Risk suitability engine as per SEBI rules
Tax Workflow
• Auto-identify PAN type and recommended ITR.
• Integration with CA desk for assisted filing.
• 15CA/CB workflow with document vault.
Agent Portal
• Ability to generate proposals referencing client portfolio.
• Commission engine integration (admin configurable).
• Alerts for benchmark breaches and opportunity calls.
Admin Portal
• User, supplier, product, and commission management.
• Logs for each critical action for audit.
PART 5 — FUTURE-PROOFING GUIDELINES
