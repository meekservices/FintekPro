2. PAN-DRIVEN ENTRY LOGIC (FOUNDATIONAL)
Step 2: PAN Context Loader (Global Middleware)

On entry into any /tax/* route:

System must:

Fetch PAN from user profile

Determine PAN type (Individual / HUF / Firm / Company / Trust / NRI)

Cache PAN context in session

User must never re-enter PAN or PAN type.

Route: /tax/itr/expert
