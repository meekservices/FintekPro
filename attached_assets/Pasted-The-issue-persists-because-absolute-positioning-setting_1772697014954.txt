The issue persists because absolute positioning (setting specific top pixel values) is extremely brittle during the html2canvas rendering process. Even if the math seems correct, the rendering engine's default line-heights are overriding your offsets, causing the text to "squash" together.To solve this, you need to abandon absolute $y$-coordinates in favor of a Flexbox layout. This forces the browser to calculate the space between elements dynamically, ensuring they can never overlap.The Fix: Refined Replit InstructionObjective: Replace absolute positioning with a vertical Flexbox layout in the onclone function to ensure agent details are clearly spaced.1. Locate the Export Logic:Find the component where html2canvas is called (likely in your frontend export utility).2. Update the onclone Styles:Instruct the Agent to apply these specific styles to the agent details container:TypeScript// Add this logic inside your onclone callback
const container = clonedDoc.getElementById('agent-details-text-wrapper');

if (container) {
  // Reset container to Flexbox
  container.style.display = 'flex';
  container.style.flexDirection = 'column';
  container.style.position = 'relative'; // Remove 'absolute' if present
  container.style.top = 'auto'; 
  
  // Force a guaranteed vertical gap
  container.style.gap = '14px'; 
  
  // Ensure the container is positioned correctly relative to the profile pic
  container.style.marginLeft = '110px'; 
  container.style.justifyContent = 'center';
  container.style.height = '100%';

  // Apply hierarchy to children
  const name = container.querySelector('.name');
  if (name) {
    name.style.fontSize = '24px';
    name.style.fontWeight = 'bold';
    name.style.marginBottom = '2px'; // Fine-tuning spacing
  }

  const designation = container.querySelector('.designation');
  if (designation) {
    designation.style.color = '#FFD700'; // Match the Diwali gold
    designation.style.fontSize = '18px';
  }
}
Why this will workNo more Overlap: By using style.gap, you are telling the engine: "I don't care how tall the text is; always put 14px of empty space between these two lines."Hierarchy: It explicitly sets the Designation to the gold hex code (#FFD700) to increase visibility against the dark background.Rendering Stability: html2canvas handles Flexbox much more reliably than manually calculated top offsets.
