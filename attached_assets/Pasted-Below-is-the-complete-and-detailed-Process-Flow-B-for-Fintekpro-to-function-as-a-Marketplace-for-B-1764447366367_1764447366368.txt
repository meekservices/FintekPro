Below is the complete and detailed Process Flow (B) for Fintekpro to function as a Marketplace for Bonds, Debentures, NCDs, SGBs, G-Secs, and Other Fixed-Income Instruments.
This design is regulator-compliant and practical for integration with RTA, Exchanges, Brokers, and Depositories.

✅ FINTEKPRO — BOND MARKETPLACE PROCESS FLOW
(For Bonds, Debentures, NCDs, SGBs, G-Secs, Market-Linked Debentures)
1️⃣ Product Discovery & Marketplace Catalog
Flow
User → Bond Marketplace Page → Filters & Sorting →
Product Details → Buy/Invest → Authentication → KYC/UCC Check
Data Comes From
Instrument Type	Source
Listed NCDs	NSE/BSE Corporate Bond Feed
Public Issue NCDs	Exchange Public Offer APIs
Tax-Free Bonds	RTA (CAMS/KFin) historical data
SGB	RBI / BSE StarSGB
G-Secs	RBI Retail Direct / Broker APIs
Unlisted/Private Bonds	Vendor feeds (GoldenPi/IndiaBonds integration or manual upload)
2️⃣ KYC / Eligibility Auto-Check
Before placing an order:
IF user has KRA Verified KYC + UCC → Proceed  
ELSE → Onboard user → PAN Check → CKYC Check → Aadhaar eKYC → Create UCC
Requirements per instrument:
Instrument	KYC Required	Additional Requirements
Listed NCDs	Full KYC	UCC mandatory
SGB	Full KYC	Bank validation
G-Secs	Full KYC	Demat mandatory
Unlisted Bonds	Full KYC	Risk consent
MLD	Accredited Investor (if needed)	Risk profiling + eSign
3️⃣ Pre-Investment Steps
Once eligible:
Fintekpro shows:
Coupon rate
Yield to maturity (YTM)
Interest/Taxation rules
Credit rating (CRISIL/ICRA)
Liquidity risk (High/Medium/Low)
Minimum investment
Call/Put options
Settlement type
Risk score
Maturity schedule
4️⃣ Order Placement Flow
User → Click BUY → Enter amount/quantity →
Fintekpro Backend Validates →
Create Order with OrderRefID →
Send Order to Provider (Exchange/Broker)
Providers can be:
NSE/BSE Bond order routing brokers (e.g., Choice, Angel, HDFC Sec)
IndiaBonds / GoldenPi B2B API
BSE STAR MF Debt module (for SGB)
5️⃣ Payment Flow
A. For Listed NCDs / Private Debt via Brokers:
Payment Link (UPI/NetBanking) → Broker Gateway →
Success Callback → Order submitted → Allotment T+1/T+2
B. For SGB via BSE:
BSE STAR SGB → Payment Gateway → Auto debit → Allotment in demat
C. For G-Sec / SDL:
Broker/RBI Retail Direct → Payment → Allotment T+1
6️⃣ Order Confirmation
Fintekpro receives:
Order ID
Status (Pending / Executed / Rejected)
Settlement date
Allotment date
Shows to user immediately.
7️⃣ Demat Settlement
On T+1/T+2:
Instrument → Depository (NSDL/CDSL) → User Demat Account
Fintekpro auto-fetches updated holdings via:
✔ Account Aggregator
✔ NSDL/CDSL Consent API
✔ CMR / Demat Statement
8️⃣ Portfolio Updating in Fintekpro
After allotment:
Fintekpro updates:

Quantity
Purchase price
Face value
YTM
Market value (if listed)
Next coupon date
Redemption schedule
9️⃣ Post-Investment Reports
Fintekpro generates:
Bond Holding Report
Transaction Ledger
Coupon Schedule
Maturity Calendar
Downloadable PDF/XLSX
Stored in Google Cloud (encrypted).
🔟 Notifications & Alerts
Fintekpro periodically sends:
Coupon credited
Maturity in 30/60/90 days
Put/Call alerts
Rating changes
Price movement alerts
1️⃣1️⃣ For Unlisted / Private / AIF-Backed Bonds
Fintekpro enables:
Term sheet download
Private placement memorandum
Risk profiling
Suitability assessment
eSign (via eMudhra)
Payment escrow
1️⃣2️⃣ Accredited Investor Flow (If MLD involved)
User Self-Declaration →
Income Proof Upload →
AI-Supported Verification →
eSign →
Accredited Status → Enabled for MLD Deals
13️⃣ Admin Portal View
Admin sees:
All bond issues
Investment pipeline
User orders
Settlement status
Coupons due
Redemption schedule
Risk Dashboard
Partner/Agent commission tracking
14️⃣ Agent/Partner Flow (If applicable)
Agent sees:
Investors mapped under him
Orders placed
Commission summary
AUM contribution
ARN/EUIN logic for MF is not used for bonds, but partner ID is stored.
15️⃣ Compliance Logging (Required by SEBI/RBI)
Fintekpro logs:
Every buy/sell order
Payment attempts
KYC verification
UCC creation
Consent text & timestamp
Order receipt from exchange
Settlement completion
Stored for 7 years.
