Prospect Proposal Module — Existing Portfolio Entry (Revamped Version)
1. OBJECTIVE
Replace the current basic portfolio input screen with a high-accuracy, ISIN-driven, multi-asset portfolio intake module that supports:
Mandatory ISIN-based security identification
Auto-fill of security metadata
Editable grid/table input
CSV/PDF import options
Instant validation + AI enrichment
Improved UX for agents and clients
This module will power AI recommendations, rebalancing logic, and proposal generation.
2. FEATURES TO IMPLEMENT
2.1 Mandatory ISIN Capture
Requirements
Add a new required field: ISIN for all market instruments.
On ISIN entry, system must:
Validate against instruments DB.
Auto-populate:
Security Name
Instrument Type (Equity/MF/Bond/ETF/MLD/Unlisted)
Category (e.g., Large Cap Equity, Corporate Bond)
Current Market Price
Display an error if ISIN not found.
API Needed
GET /instrument/{isin}
Response: name, type, category, live price, last updated.
2.2 Portfolio Editable Table (Spreadsheet Style)
Replace the existing form with a table grid:
Columns required:
ISIN (text, required)
Security Name (auto-filled, read-only)
Type (auto-filled, editable fallback)
Category (auto-filled)
Quantity
Buy Price / Buy NAV
Buy Date
Notes
Current Value (auto-calculated)
Actions: Delete Row
Components
Use AgGrid, Material Table, or equivalent.
UI Requirements
Add Row button
Inline validation
Total portfolio value summary at bottom
Sticky header on scroll
2.3 Multi-Asset Class Segmentation
Split portfolio input into cards:
Equities
Mutual Funds
Bonds & MLDs
AIF/PMS
Unlisted Equity
Other Assets (FD, Gold, RE)
Each card contains an editable table.
