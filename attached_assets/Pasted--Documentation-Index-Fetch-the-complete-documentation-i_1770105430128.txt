# Sheet JSON

APIs with volumetric data either require or respond with a sheet structure. A sheet structure mimics an Excel or Google Sheet. This allows API users to send or receive more data in a smaller JSON format. The sheet contains multiple blocks, which organize data either in a table or list format.

[View an example workbook for TDS Form 24Q.](https://docs.google.com/spreadsheets/d/1GS3LVBYxAturviZ-NgzC20yJwDI0hQiy/edit?gid=105692586#gid=105692586)

In the preceeding workbook, there are four separate sheets, each containing different types of data. The same data represented in a JSON format would look like below.
