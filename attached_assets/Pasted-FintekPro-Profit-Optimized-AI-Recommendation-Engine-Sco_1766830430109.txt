EPIC 0: Guardrails (READ FIRST)

EPIC 1: Numeric Scoring Engine (Balanced vs Growth-Optimized)
TASK 1.1 – Formalize Suitability Score (S)
Description
Implement a normalized Suitability Score (0–100) as a prerequisite gate.
Formula
S = (Risk Match × 0.35)
  + (Time Horizon Match × 0.25)
  + (Liquidity Match × 0.20)
  + (Regulatory Eligibility × 0.20)
Rules
If S < 60 → product excluded from recommendation pipeline
Acceptance Criteria
Suitability score is logged and auditable
Ineligible products never reach ranking stage
TASK 1.2 – Implement Upside Potential Score (U) per Asset Class
Description
Add deterministic, rule-based Upside Score calculators.
Required Implementations
Stocks
Mutual Funds
Bonds / MLD
REITs / InvITs
IPOs
Unlisted Equity
AIF / PMS
Acceptance Criteria
All U scores normalized to 0–100
No AI calls used for scoring
Inputs are explainable and logged
TASK 1.3 – Final Score Calculation by Mode
Description
Apply different weightings based on recommendation mode.
Formulas
Balanced
Final = (S × 0.70) + (U × 0.30)
Growth-Optimized
Final = (S × 0.55) + (U × 0.45)
Acceptance Criteria
Mode selection changes ranking order
Allocation caps enforced post-scoring
