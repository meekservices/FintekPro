🟥 PHASE 2 — KYC SUITABILITY & COMPLIANCE CHECK
Before a user can BUY any bond/NCD:
✔ Step 1 — Check KYC
PAN verified via Sandbox API
CKYC fetched using AuthBridge CKYC API
KRA status validated using Protean (NSDL KRA)
If KYC is Verified → Move ahead
If Not Verified → Aadhaar eKYC via Cashfree → Push KYC to CKYC registry
✔ Step 2 — Check Demat Availability
Required because ALL bonds are credited to the user’s NSDL/CDSL demat account.
Fintekpro fetches:
DP + Client ID
Demat Account Status
ISIN Eligibility
✔ Step 3 — Risk Suitability Check
SEBI Requirements:
Client must accept “High Risk Debt” warning
Acknowledge default risk
Confirm coupon reinvestment understanding
UHNWI: Accredited Investor route (if required for private placement)
🟥 PHASE 3 — ORDER PLACEMENT FLOW
For Listed Bonds / SGB / G-Secs via NSE/BSE
User selects a bond
Enters amount (₹) or units
Fintekpro calls:
POST /api/bonds/order/place
Backend checks:
KYC verified?
Demat active?
ISIN eligible for purchase?
Price + YTM fetched?
Order submitted to:
BSE Bond Order Routing OR
NSE NCBP (Non-Competitive Bidding Platform) OR
RBI Retail Direct API for G-Secs (if integrated)
Payment Flow:
NetBanking/UPI (via Cashfree Payment Gateway)
Funds go directly to:
→ Clearing Corporation (Indian Clearing Corp Ltd)
Order Confirmation:
Exchange returns an Order ID
Allotment happens on T+1 or T+2
Bonds credited to demat via NSDL/CDSL

🟥 PHASE 6 — SELL / REDEMPTION FLOW
Two ways:
1. Exchange Sell Order (If Bond is listed)
Market sell → BSE/NSE
Settlement → T+1
Funds to bank account
2. Off-Market Transfer (For Private Bonds / Unlisted NCDs)
Delivery Instruction Slip (DIS) or eDIS (NSDL)
Buyer → matched via marketplace
Price discovery via negotiation
Fintekpro charges platform fee
