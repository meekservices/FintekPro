6. BACKEND – REPORT ORCHESTRATOR SERVICE
6.1 Pre-Flight Validation Engine (MANDATORY)
Before generating report:
Check	Action
Insufficient history	Auto-disable affected section
Missing allocation model	Disable Target Allocation
Missing distribution data	Skip Price & Distribution
Risk-free rate	Use system default
Disclosure version	Lock by report date
Return validation summary to UI.
6.2 Section-Wise Computation Engine
Each section = independent module.
/services/reports/
 ├── portfolioXray.ts
 ├── riskReward.ts
 ├── rollingReturns.ts
 ├── correlationMatrix.ts
 ├── disclosures.ts
Rules:
No shared state between sections
All accept (portfolioData, sectionConfig)
6.3 PDF / Excel Renderer
PDF: page-per-section
Excel: sheet-per-section
Respect orientation & font size
Add disclosure footer on every page
7. TEMPLATE MANAGEMENT
