2. Update the onclone Logic
When html2canvas clones the element for export, it sometimes loses Flexbox "gap" properties. Use this onclone function to force the layout:

TypeScript
const canvas = await html2canvas(element, {
  onclone: (clonedDoc) => {
    const container = clonedDoc.getElementById('agent-details-text-wrapper');
    if (container) {
      // Force Flexbox layout for the export engine
      container.style.display = 'flex';
      container.style.flexDirection = 'column';
      
      // Use margin-bottom on children as a fallback for 'gap' support
      const children = container.children;
      for (let i = 0; i < children.length; i++) {
        (children[i] as HTMLElement).style.marginBottom = '10px';
        (children[i] as HTMLElement).style.position = 'relative';
        (children[i] as HTMLElement).style.top = '0px'; // Reset any absolute top
      }

      // Explicitly color the designation Gold
      const designation = clonedDoc.querySelector('.agent-designation') as HTMLElement;
      if (designation) designation.style.color = '#FFD700';
    }
  }
});
Why this works:
Removes the "Collision": By removing top: 26px, top: 49px, etc., you eliminate the fixed "slots" that the text is currently overfilling.

Guaranteed Gaps: The marginBottom or gap-y-2 acts as a physical barrier between lines.

Better Contrast: Using #FFD700 (Gold) for the designation makes it pop against the purple background much better than white.
