Replit Instruction
Upgrade Fixed Income System – Instrument Classification & Daily Status Engine
Objective
Upgrade the existing Fixed Income module at FintekPro to:
Support all listed and unlisted debt instruments
Classify each instrument into:
SELLABLE
VISIBLE (Non-Sellable)
HIDDEN
Recalculate and update status daily (T+0 / T+1) based on liquidity, rating, structure, and regulatory rules
Ensure advisor UI, AI recommendations, and compliance logic respect this classification
A. DATA MODEL CHANGES (MANDATORY FIRST STEP)
1. Extend Existing fixed_income_instruments Table
Add the following columns (do NOT drop existing fields):
ALTER TABLE fixed_income_instruments
ADD COLUMN instrument_status VARCHAR(16) NOT NULL DEFAULT 'HIDDEN',
ADD COLUMN is_listed BOOLEAN NOT NULL,
ADD COLUMN liquidity_score INTEGER,
ADD COLUMN rating_current VARCHAR(10),
ADD COLUMN rating_date DATE,
ADD COLUMN rating_trend VARCHAR(10),
ADD COLUMN structure_complexity INTEGER,
ADD COLUMN regulatory_eligibility VARCHAR(32),
ADD COLUMN last_trade_date DATE,
ADD COLUMN bid_ask_spread DECIMAL(5,2),
ADD COLUMN status_reason TEXT,
ADD COLUMN status_last_updated TIMESTAMP;
Status Enum (Strict)
SELLABLE
VISIBLE
HIDDEN
B. UNIFIED BOND UNIVERSE INGESTION
2. Create Separate Ingestion Pipelines
a) Listed Bonds Pipeline
Source: Exchanges + Depositories
Identifier: ISIN (primary key)
Update frequency: Daily EOD
b) Unlisted / Privately Placed Bonds Pipeline
Source: Depository + issuer disclosures
Identifier: ISIN (mandatory)
Default visibility: HIDDEN
Upgrade path: HIDDEN → VISIBLE only
Rule:
Unlisted instruments can never default to SELLABLE.
C. STATUS CLASSIFICATION ENGINE (CORE FEATURE)
3. Create a Daily Status Evaluation Service
Create a new service/module:
services/fixed_income_status_engine/
Entry Function
evaluateInstrumentStatus(isin)
Evaluation Gates (Executed in Order)
Gate 1: Data Completeness
Missing price / rating / maturity → HIDDEN
Gate 2: Regulatory Eligibility
Retail allowed → continue
Institutional only → VISIBLE
Gate 3: Liquidity
Liquidity score ≥ 60
Bid-ask spread ≤ 1.25%
Last trade ≤ 3 trading days
Else → VISIBLE
Gate 4: Credit Quality
Rating ≥ A+ → continue
Below A+ → VISIBLE
Gate 5: Structural Simplicity
Callable / subordinated / step-up complexity > threshold → VISIBLE
Pass All Gates → SELLABLE
4. Persist Decision with Explanation
Every status change must write:
{
  "instrument_status": "VISIBLE",
  "status_reason": "Bid-ask spread exceeds threshold",
  "status_last_updated": "timestamp"
}
This is non-optional for SEBI auditability.
D. DAILY AUTOMATION (CRITICAL)
5. Replit Cron Job (Daily)
Configure a scheduled job:
cron/fixed_income_daily_refresh.ts
Runs every trading day:
Refresh prices
Refresh ratings
Recalculate liquidity
Re-run status engine for ALL active ISINs
Log all status transitions
Important:
Status changes are append-only logs, not overwrites.

6. Update Fixed Income APIs
Advisor Search API
GET /advisor/fixed-income/search

instrument_status = SELLABLE
Holdings & Analysis API
GET /portfolio/holdings

SELLABLE + VISIBLE
System / AI APIs
Full universe access
Hidden instruments excluded from UI responses

7. Advisor UI Controls

VISIBLE	View-only + warning banner
HIDDEN	Not visible

“This instrument is shown for reference only and cannot be recommended or transacted.”
