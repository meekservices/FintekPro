EPIC: Stock Intersection Analysis in Portfolio Review
Objective
Detect and quantify overlapping underlying stocks across mutual funds in a client portfolio to:
Identify hidden concentration risk
Improve diversification scoring
Support rebalancing & recommendation logic
Strengthen proposal credibility (advisor-grade)
WHAT THIS FEATURE DOES (CLEARLY)
When a prospect has multiple mutual funds:
Look through fund holdings
Identify same stocks appearing in multiple funds
Compute:
Stock-wise exposure %
Fund-wise contribution
Surface over-concentration risks
BACKEND TICKETS
BE-01: Mutual Fund Holdings Master Table
Type: Backend – Database
Priority: P0
Description
Store scheme-level stock holdings for look-through analysis.
Schema
CREATE TABLE mf_holdings (
  id UUID PRIMARY KEY,
  mf_isin VARCHAR(20),
  stock_symbol VARCHAR(30),
  stock_name TEXT,
  sector VARCHAR(100),
  holding_percentage NUMERIC(6,3),
  holding_date DATE,
  source VARCHAR(20),
  UNIQUE (mf_isin, stock_symbol, holding_date)
);
Notes
holding_percentage = % of fund AUM
Store latest portfolio date only for analysis
Historical optional (future)
Acceptance Criteria
One row per stock per fund
No duplicate holdings for same date
BE-02: MF Holdings Ingestion Job
Type: Backend – Data Ingestion
Priority: P0
Description
Ingest mutual fund portfolio holdings (monthly/quarterly).
Data Sources (Priority Order)
AMFI monthly portfolio disclosure
AMC scheme portfolio PDFs (parser later)
Tasks
Create cron syncMfHoldings()
Parse ISIN → stocks → weight %
Upsert latest holdings
Mark holding_date
Acceptance Criteria
≥95% schemes populated
Latest disclosure always used
Old data retained but ignored by default
BE-03: Portfolio Look-Through Engine
Type: Backend – Analytics
Priority: P0
Description
Compute client-level stock exposure across all funds.
Input
[
  { "mf_isin": "INF123", "portfolio_weight": 0.25 },
  { "mf_isin": "INF456", "portfolio_weight": 0.35 }
]
Logic
stock_exposure =
  Σ (fund_weight × stock_holding_percentage)
Output
{
  "RELIANCE": {
    "total_exposure": 0.118,
    "funds": [
      { "isin": "INF123", "contribution": 0.045 },
      { "isin": "INF456", "contribution": 0.073 }
    ]
  }
}
Acceptance Criteria
Accurate aggregation
Ignore funds with missing holdings
Deterministic output
BE-04: Stock Intersection Detection Engine
Type: Backend – Analytics
Priority: P0
Description
Identify stocks appearing in 2 or more funds.
Rules
Intersection threshold: ≥2 funds
Configurable threshold (future)
Output

}
Risk Flags
Exposure %	Flag

<5%	LOW
