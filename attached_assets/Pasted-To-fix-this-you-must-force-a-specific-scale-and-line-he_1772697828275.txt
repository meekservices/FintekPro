const handleExportPNG = async () => {
  const element = document.getElementById('greeting-card');
  if (!element) return;

  // Use a scale of 3 to ensure text remains sharp and doesn't "bleed"
  const canvas = await html2canvas(element, {
    useCORS: true,
    scale: 3, 
    logging: false,
    letterRendering: true, // Improves font spacing accuracy
    backgroundColor: null,
    onclone: (clonedDoc) => {
      const container = clonedDoc.getElementById('agent-text-block');
      if (container) {
        // FORCE CONTAINER HEIGHT AND FLEX
        container.style.display = 'flex';
        container.style.flexDirection = 'column';
        container.style.justifyContent = 'center';
        container.style.gap = '10px'; // Explicit gap for export
        container.style.height = '100px'; 

        // FORCE EACH TEXT ELEMENT TO REMAIN WITHIN BOUNDS
        const name = clonedDoc.querySelector('.agent-name') as HTMLElement;
        const designation = clonedDoc.querySelector('.agent-designation') as HTMLElement;
        const contactRows = clonedDoc.querySelectorAll('.agent-contact') as NodeListOf<HTMLElement>;

        if (name) {
          name.style.fontSize = '20px';
          name.style.lineHeight = '24px'; // Fixed px height prevents overlap
          name.style.marginBottom = '2px';
        }

        if (designation) {
          designation.style.fontSize = '14px';
          designation.style.lineHeight = '18px';
          designation.style.color = '#FFD700';
          designation.style.marginBottom = '6px';
        }

        contactRows.forEach(row => {
          row.style.display = 'flex';
          row.style.alignItems = 'center';
          row.style.fontSize = '12px';
          row.style.lineHeight = '16px';
          row.style.marginBottom = '4px';
        });
      }
    }
  });

  const link = document.createElement('a');
  link.download = `diwali-greeting.png`;
  link.href = canvas.toDataURL('image/png', 1.0);
  link.click();
};
Why the text size was differing:
DPI Scaling: Your dashboard is likely viewed on a screen with a devicePixelRatio of 2 or higher. html2canvas often captures at "1" unless told otherwise, making text look larger and "squashed" in the final file.

Relative vs. Absolute Line-Height: In your live preview, leading-tight (relative) works. In export, you need Absolute Pixel Line-Heights (e.g., line-height: 24px) so the text takes up the exact same physical space every time.

Gap Support: Many export engines struggle with gap. The code above uses explicit marginBottom inside the onclone function as a fallback to ensure the lines stay separated.
