TICKET: Progressive MLM Payout Engine (Remaining-Based)
Type: Backend – Commission Engine
Priority: P0
Service: CommissionPayoutService
1. Objective
Implement a remaining-balance MLM payout engine where:
Agent gets a fixed %
Platform gets a fixed %
Each upline partner gets X% of the remaining amount
Distribution continues up the hierarchy
Final residual goes to Operational Expenses

4. Payout Algorithm (Authoritative)
Entry Point
CommissionPayoutService.processTransaction(transactionId)
Step-by-Step Logic
processTransaction(transactionId) {
  txn = getTransaction(transactionId)
  config = getActiveCommissionConfig(txn.product_type)

  total = txn.gross_commission

  // Step 1: Agent payout
  agentAmount = total * (config.agent_pct / 100)
  credit(txn.seller_partner_id, agentAmount, 'AGENT', 0)

  // Step 2: Platform fee
  platformAmount = total * (config.platform_pct / 100)
  credit(PLATFORM_ACCOUNT, platformAmount, 'PLATFORM', null)

  // Step 3: MLM Incentive Pool
  remaining = total - agentAmount - platformAmount

  level = 1
  currentPartner = getParent(txn.seller_partner_id)

  // Step 4: Progressive Upline Distribution
  while (currentPartner && remaining >= config.min_residual_threshold) {

    if (!isEligible(currentPartner)) {
      currentPartner = getParent(currentPartner.partner_id)
      level++
      continue
    }

    incentive = remaining * (config.upline_incentive_pct / 100)

    credit(
      currentPartner.partner_id,
      incentive,
      'UPLINE',
      level
    )

    remaining -= incentive
    currentPartner = getParent(currentPartner.partner_id)
    level++
  }

  // Step 5: Operational Residual
  if (remaining > 0) {
    credit(OPERATIONAL_ACCOUNT, remaining, 'OPERATIONS', null)
  }

  markTransactionCommissioned(transactionId)
}
