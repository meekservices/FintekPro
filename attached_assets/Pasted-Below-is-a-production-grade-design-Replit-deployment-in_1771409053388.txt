4️⃣ AUTO-PROMOTION LOGIC
Node service:
async function promoteModelIfValid(candidateModel) {
   const activeModel = await getActiveModel()

   if (candidateModel.sharpe >= activeModel.sharpe &&
       candidateModel.roc >= 0.65) {

       archive(activeModel)
       activate(candidateModel)
   }
}
No admin approval required.
