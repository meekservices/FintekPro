✅ 7. BACKEND BEHAVIOR FOR THE NEW FLOW
Database Changes
Add new column in AMC table:
regular_plans_enabled (boolean)
Scheme table:
is_published (boolean)
plan_type ENUM (Regular, Direct)
Logic: AMC Toggle → Scheme Sync
When AMC toggle = ON:
UPDATE schemes 
SET is_published = TRUE 
WHERE amc_id = {id} AND plan_type = "Regular";
When AMC toggle = OFF:
UPDATE schemes 
SET is_published = FALSE 
WHERE amc_id = {id} AND plan_type = "Regular";
Prevent Editing Direct Plans
Filter: WHERE plan_type = "Regular" always applied.
