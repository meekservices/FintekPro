EPIC: Overlap-Aware Intelligence Engine (Portfolio → Action)
Objective
Convert stock overlap insights into:
Smarter fund recommendations
“Replace fund” suggestions
Quantified diversification impact
Auto-generated advisor talking points
BACKEND TICKETS
BE-10: Diversification Scoring Engine
Type: Backend – Analytics
Priority: P0
Description
Introduce a numeric diversification score that penalizes stock & sector overlap.
Score Definition
Base Score = 100

Penalties:
- Stock overlap >10% → −15
- Stock overlap 5–10% → −8
- Sector exposure >30% → −10
- >3 funds holding same stock → −5 per extra fund
Output
{
  "diversification_score": 68,
  "penalties": [
    { "type": "STOCK_OVERLAP", "stock": "RELIANCE", "impact": -15 },
    { "type": "SECTOR_CONCENTRATION", "sector": "Banking", "impact": -10 }
  ]
}
Acceptance Criteria
Score range 0–100
Deterministic output
Used across UI + PDF + recommendations
BE-11: Overlap-Aware Fund Suitability Filter
Type: Backend – Recommendation Logic
Priority: P0
Description
Modify fund recommendation engine to penalize candidate funds that increase overlap.
Logic
For each candidate fund:
overlap_risk_score =
  Σ (candidate_stock_weight × existing_portfolio_stock_exposure)

If overlap_risk_score > threshold → downgrade ranking
Thresholds
Overlap Risk	Action
>8%	Exclude
4–8%	Rank lower
<4%	Allowed
Acceptance Criteria
No recommended fund increases top stock exposure
Category & risk profile rules still respected
BE-12: “Replace Fund” Detection Engine
Type: Backend – Analytics
Priority: P0
Description
Identify funds that are redundant due to high overlap.
Replacement Conditions
A fund is replaceable if:
≥40% holdings overlap with another fund AND
Lower Sharpe / higher expense ratio OR
Lower diversification contribution
Output
{
  "replace_fund": "ABC Large Cap Fund",
  "reason": "High overlap with XYZ Large Cap (42%) and lower Sharpe",
  "suggested_action": "Switch"
}
Acceptance Criteria
Never suggest replacing the only fund in a category
No circular replacements
BE-13: Alternative Fund Selector (Low Overlap)
Type: Backend – Recommendation
Priority: P0
Description
For each replaceable fund, suggest lower-overlap alternatives.
Filters
Same category
Same or lower risk
Stock overlap <5%
Better or equal metrics (Sharpe, TER)
Output
{
  "original_fund": "ABC Large Cap",
  "alternatives": [
    {
      "fund": "DEF Large Cap",
      "overlap_reduction": "−28%",
      "diversification_gain": "+12"
    }
  ]
}
