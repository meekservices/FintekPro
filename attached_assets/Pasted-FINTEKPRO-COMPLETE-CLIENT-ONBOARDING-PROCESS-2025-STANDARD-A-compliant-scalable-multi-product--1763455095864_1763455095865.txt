FINTEKPRO – COMPLETE CLIENT ONBOARDING PROCESS (2025 STANDARD)
A compliant, scalable, multi-product onboarding flow
STEP 0 — Entry Point (User → Fintekpro)
User lands on:
✔ Web (Fintekpro.com)
✔ App
✔ Agent referral link (?agent_id=XYZ)
✔ Partner/DSA shared onboarding link
Frontend captures:
Mobile / Email
Password or OTP login
Referral agent ID (if available)
STEP 1 — User Account Creation
Backend creates:
user_id
default_status = 'pending_kyc'
assigned_agent_id (referral_link OR default_agent)
created_at, updated_at
Log event into Audit Ledger:
EVENT: USER_CREATED
METADATA: IP, device, browser
STEP 2 — PAN Collection
User enters PAN
→ System does real-time PAN validation using Cashfree or Protean API
Check:
✔ Name match
✔ DOB match (if provided)
✔ Format validation
Store in KYC Vault:
pan_number (encrypted)
name_from_pan
timestamp
STEP 3 — KRA Status Check (Protean NSDL KRA / CVL KRA)
Fintekpro → Protean API using:
PAN + DOB
Response:
VERIFIED (GREEN)
ONHOLD
KYC_NOT_FOUND
REJECTED
If KRA VERIFIED → Go to Step 6 (UCC Creation Ready)
If Not Verified → Move to Step 4 (Aadhaar eKYC)
Log in Audit:
EVENT: KRA_STATUS_CHECK
STATUS: VERIFIED / NOT VERIFIED
STEP 4 — Aadhaar eKYC (Cashfree OKYC)
User performs:
✔ Aadhaar OTP eKYC
✔ Liveliness check (if Smart KYC)
✔ Face match
✔ Address extraction
Cashfree returns:
Aadhaar XML package
Address
Photo
DOB
Gender
Store minimal compliant data in KYC Vault.
STEP 5 — CKYC Registration (If Required)
If KYC not found earlier:
Fintekpro prepares a CKYC Upload Package:
PAN
Aadhaar XML
Photo
Address
Signature (optional)
Submit to Protean NSDL KRA → CKYC creation
Wait 1–48 hours → Polling API
Once CKYC KIN received → update KYC Vault
Audit log:
EVENT: CKYC_CREATED
KIN_NUMBER: xxxxxxxxxx
STEP 6 — BSE STAR MF UCC Creation
Once KRA Verified (either before OR after eKYC):
Fintekpro auto-fills UCC form:
✔ Name
✔ PAN
✔ DOB
✔ Address
✔ Email/Mobile
✔ Bank Details
✔ Nominee
✔ FATCA
✔ Guardian (if minor)
Submit via:
BSE AddInvestor API
BSE returns:
ucc_id
status = ACTIVE
Audit log:
EVENT: UCC_CREATED
UCC_ID: XXXX
STEP 7 — Bank Verification (Mandatory)
User enters account no. + IFSC → Cashfree Penny Drop
Response:
Name match
Account status
Bank type
Verification reference
Store in DB
STEP 8 — Mandate Registration (for SIP)
Submit mandate via:
✔ Cashfree eMandate API
or
✔ eMudhra Aadhaar eSign (NACH PDF)
Once mandate active:
mandate_id
status: ACTIVE
STEP 9 — Risk Profiling (SEBI Required)
User answers 6–10 questions
System assigns risk profile:
Conservative
Moderate
Aggressive
Store in DB
→ Required for Advisory & RIA flows
→ Optional for MFD flows
STEP 10 — Agent Mapping Logic (Automatic + Admin Controlled)
Mapping priority:
IF agent referral link present → assign that agent
ELSE → assign default agent
Admin can override any time
Update:
client.agent_id = XYZ
Audit:
EVENT: AGENT_ASSIGNED
AGENT_ID: XYZ
METHOD: AUTO / ADMIN
STEP 11 — FINTEKPRO PORTFOLIO AUTO-FETCH (After KYC Completion)
Once KYC is stored, Fintekpro auto-fetches:
A) MF Holdings via:
BSE STAR GetHoldingReport
CAS via CAMS/KFin
Account Aggregator Demat + MF statement
B) Demat Holdings via:
NSDL/CDSL through Account Aggregator
C) Retirement Assets (If enabled):
EPF
PPF
NPS
APY
D) Unlisted Shares
NSDL/CDSL ISIN map
ESOP portals
Company registrars
All shown under My Portfolio inside Fintekpro.
STEP 12 — Compliance Confirmation
Before allowing MF purchase, show final disclosure:
User must agree to:
✔ FATCA
✔ Risk Profile
✔ EUIN declaration (MFD only)
✔ Terms & Conditions
✔ Privacy & Consent policy
Store digitally signed consent.
STEP 13 — Ready to Invest 🎉
User can now:
Buy Mutual Funds
Start SIP
Invest in Bonds/ETF (if supported)
Apply for Insurance/Loans
Access Analytics Dashboard
Everything is tracked
✔ with ARN/EUIN mapping
✔ with agent commission routing
✔ with audit logging
✔ with regulatory-ready logs
