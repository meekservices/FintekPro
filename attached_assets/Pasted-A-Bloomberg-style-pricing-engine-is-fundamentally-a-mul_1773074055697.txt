For FintekPro, the engine should support:
Listed equities
Mutual funds

Structured products
The goal is to produce auditable, SEBI-compliant valuation prices for PMS/AIF portfolios.
1. Concept: Golden Source Pricing
Institutional systems do not trust one data provider. They use price hierarchy logic.
Example hierarchy:
Primary Source → Exchange close price
Secondary Source → Alternate exchange
Fallback → Last traded price
Fallback 2 → Model price
Fallback 3 → Broker quote
The engine produces:
Final Price = Best Valid Price Based on Hierarchy

All institutional pricing systems start with a security master.
Example table:
CREATE TABLE security_master (

    symbol VARCHAR(50),
    asset_class VARCHAR(30),

    currency VARCHAR(10),

6. Price Validation Rules
Institutional systems apply sanity checks.
Example rules:
If price deviation > 20% from previous close → flag
If volume = 0 → ignore price
If stale price > 5 days → fallback source
Python example:
def validate_price(price, prev_price):

    change = abs(price - prev_price) / prev_price

    if change > 0.20:
        return False

    return True
7. Pricing Hierarchy Logic
Example algorithm:
def get_best_price(prices):

    hierarchy = [
        "NSE_CLOSE",
        "BSE_CLOSE",
        "LAST_TRADE",
        "MODEL_PRICE",
        "BROKER_QUOTE"
    ]

    for source in hierarchy:
        if source in prices:
            return prices[source]

    return None
8. Unlisted Share Pricing Engine
Unlisted assets require valuation models.
Typical methods used by PMS/AIF:
Comparable valuation
Price = Peer EV/EBITDA × Company EBITDA
Last funding round
Price = last funding valuation / shares outstanding
Discount model
Fair Value = Last round × liquidity discount (20–40%)
Python example:
def unlisted_price(last_round_price):

    liquidity_discount = 0.30

    return last_round_price * (1 - liquidity_discount)
9. Bond Pricing Engine
Debt instruments are priced using yield curves.
Formula:
Bond Price = Σ (Coupon / (1+y)^t) + Principal/(1+y)^T
Python example:
import numpy as np

def bond_price(face, coupon, yield_rate, maturity):

    price = 0

    for t in range(1, maturity+1):
        price += coupon / (1+yield_rate)**t

    price += face / (1+yield_rate)**maturity

    return price
10. Derivatives Pricing
Derivatives typically use Black-Scholes.
Call Price =
S*N(d1) − K*e^(−rt)*N(d2)
Python:
from mpmath import log, sqrt, exp
from scipy.stats import norm

def black_scholes(S, K, r, t, sigma):

    d1 = (log(S/K) + (r + sigma**2/2)*t) / (sigma*sqrt(t))
    d2 = d1 - sigma*sqrt(t)

    return S*norm.cdf(d1) - K*exp(-r*t)*norm.cdf(d2)
