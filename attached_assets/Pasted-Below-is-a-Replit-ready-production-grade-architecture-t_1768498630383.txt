3. Core Services (What Runs in Production)
3.1 API Gateway (Edge Layer)
Responsibilities
Authentication (JWT / OAuth)
Rate limiting
Role-based access
Request logging
Endpoints
GET /company/{cin}
GET /company/{cin}/financials
GET /company/{cin}/risk
No business logic here.
3.2 Company Service (Most Important)
Single Source of Truth API
Lookup Flow
1. Check Redis cache
2. Check FintekPro DB
3. Fallback to Sandbox
4. Persist → Cache → Return
5. Trigger async MCA enrichment
Key Rule
UI never talks to Sandbox directly.
3.3 Sandbox Client (Isolated Package)
Purpose
CIN bootstrap only
Controlled usage
Replaceable in future
Controls
Circuit breaker
Quota enforcement
Retry + timeout
Response normalization
Output
{
  "data_source": "SANDBOX",
  "confidence": "SUMMARY"
}
3.4 MCA Ingestion Service (System of Record Builder)
Responsibilities
Bulk MCA data pull
XBRL parsing
Financial normalization
Versioning
Runs
Nightly batches
On-demand enrichment jobs
Stores
Raw filings (object storage)
Parsed data (Postgres)
Derived facts (analytics DB)
3.5 Analytics Service (FintekPro Differentiator)
Consumes
MCA-normalized financials
Produces
Financial ratios
Trend indicators
Risk scores
Health grades
Never reads Sandbox data directly
3.6 Worker Service (Async Backbone)
Triggers
Sandbox fallback usage
Cache expiry
New MCA filings
Analytics recomputation
Queue-based
Redis / BullMQ / Temporal-style

5. Canonical API Contract (Non-Negotiable)
GET /company/{cin}
Always returns best available data.
{
  "company": {...},
  "financials": {...},
  "directors": [...],
  "risk": {...},
  "data_quality": {
    "source": "MCA | SANDBOX",
    "confidence": "AUDIT_GRADE | SUMMARY",
    "last_updated": "YYYY-MM-DD"
  }
}
UI logic depends on confidence, not source.
6. Cache Strategy (Cost & Performance Control)
Data Type	TTL	Refresh Mode
Company profile	30 days	Soft refresh
Directors	30 days	Background
Financials	365 days	Immutable
Charges	7 days	Priority
Rule
Never block UI waiting for refresh.
7. Compliance & Legal Safeguards (Built-In)
Store source_form and filing_date
Maintain raw filing references
Display disclaimer automatically when confidence = SUMMARY
Log every external API hit
Restrict raw data access to admin roles
