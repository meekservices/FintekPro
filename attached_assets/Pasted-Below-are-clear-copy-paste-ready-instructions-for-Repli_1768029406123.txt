Below are clear, copy-paste–ready instructions for Replit to install an internal “MCA Support & Intelligence Service” inside FintekPro, specifically to attend MCA-related queries, workflows, and analytics.
This is written as an engineering + product instruction, not marketing copy.
Replit Instructions
Install MCA Support & Intelligence Service for FintekPro
Purpose
Create an internal service that:
Handles MCA-related queries from ops, compliance, and advisors
Tracks MCA filings, downloads, and bulk access status
Supports Profitable Company Radar analytics
Is SEBI- and audit-ready
Primary data authority: Ministry of Corporate Affairs (MCA V3)
1. Create a New Backend Service
Service Name
mca-intelligence-service
Responsibility
MCA data ingestion
Filing metadata storage
Query handling
Audit logging
Analytics support (no raw redistribution)
2. Database Schema (Mandatory)
2.1 MCA Company Master
mca_company_master
- cin (PK)
- company_name
- company_status
- incorporation_date
- registered_state
- last_filing_year
- created_at
2.2 MCA Financial Snapshot (Derived Only)
mca_financial_snapshot
- id (PK)
- cin (FK)
- financial_year
- revenue
- profit_before_tax
- profit_after_tax
- net_worth
- source = 'MCA_AOC4_XBRL'
- derived_at
❗ Do NOT store raw AOC-4 or XBRL files long term.
2.3 MCA Filing Tracker
mca_filing_tracker
- id (PK)
- cin
- filing_type (AOC-4 / XBRL)
- filing_year
- downloaded_by
- download_date
- wallet_cost
- status (SUCCESS / FAILED)
2.4 MCA Query Log (For Support & Audit)
mca_query_log
- id (PK)
- user_id
- query_type
- cin (nullable)
- action_taken
- response_summary
- created_at
3. Backend APIs to Build
3.1 MCA Query Handling API
POST /api/mca/query
Supported query types
Company financial availability
Last filed AOC-4 year
Profit > ₹1 Cr check
Filing missing / delayed
MCA wallet usage check
3.2 MCA Filing Ingestion API (Manual Trigger)
POST /api/mca/ingest
Input:
CIN
Filing Year
Uploaded XBRL file (manual / admin only)
Process:
Parse XBRL
Extract PAT, PBT, revenue
Store derived metrics
Log filing source
3.3 Profitable Company Filter API
GET /api/mca/profitable-companies?pat_min=10000000
Returns:
CIN
Company Name
PAT
Financial Year
4. XBRL Parsing Module
Module Name
mca-xbrl-parser
Responsibilities
Accept XBRL input
Extract:
ProfitAfterTax
ProfitBeforeTax
RevenueFromOperations
NetWorth
Normalize values
Return structured JSON
❗ Parsing is internal only. No public exposure.
5. Admin UI (FintekPro Internal)
Section: MCA Intelligence
Screens to Build
MCA Wallet Status
Current balance
Monthly spend
Filing Download Tracker
CIN
Year
Status
Profitable Company Radar
Filter: PAT > ₹1 Cr
Sector

MCA Query Console

“Does this company qualify?”
6. Role-Based Access Control
Role	Access
Admin	Full
Compliance	Read + Query
Advisor	Read-only insights
Ops	Filing ingestion
7. Compliance & Guardrails (Hard Rules)
Replit must enforce:
No Web Scraping
No CAPTCHA Bypass
No Raw MCA File Redistribution
Derived Data Only
Source Attribution Stored Per Record
Mandatory disclosure string:
“Derived from statutory public filings sourced from MCA.”
8. Logging & Audit (Mandatory)
Every action must log:
User ID
Timestamp
CIN (if applicable)
Purpose (query / ingestion / analysis)
This supports:
SEBI inspection
Internal audit
Legal defensibility
9. Deployment Checklist
 Service deployed as independent module
 Database migrations applied
 RBAC enforced
 Admin UI enabled
 Logging verified
 No raw MCA files exposed
10. Internal Positioning (For Dev Team)
“This service converts MCA statutory filings into compliant, derived intelligence for advisory and analytics — not a data resale engine.”
