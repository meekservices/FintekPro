FINTEKPRO – MCA COMPANY DATA PLATFORM
Agile Backlog (Replit-Ready)
EPIC 1: MCA Data Ingestion & Source Management
Goal: Reliably ingest, version, and store MCA filings without live UI dependency.
User Story 1.1 – MCA Source Configuration
As a system admin
I want configurable MCA data sources
So that ingestion is auditable and extensible
Tasks
Create mca_sources table (source_name, form_type, refresh_cycle)
Add source enable/disable flag
Store filing metadata (form, FY, filing_date)
Add checksum/hash for file integrity
Build admin config JSON loader
User Story 1.2 – MCA Filing Downloader
As a data pipeline
I want automated MCA filing downloads
So that data refresh is consistent
Tasks
Build MCA authentication handler (session-based)
Implement bulk filing fetch (AOC-4, MGT-7)
Support XBRL + non-XBRL formats
Store raw files in object storage
Log ingestion run ID
EPIC 2: ETL & Normalization Engine
Goal: Convert raw MCA filings into structured, queryable datasets.
User Story 2.1 – XBRL Parser Engine
As a backend service
I want structured XBRL parsing
So that financial data is normalized
Tasks
Parse AOC-4 XBRL taxonomy
Map tags → internal financial schema
Handle missing/optional fields
Validate numeric & date formats
Store parsed JSON snapshot
User Story 2.2 – Normalized Financial Tables
As a data analyst
I want standardized financial tables
So that analytics is consistent
Tasks
Create financial_statements table
Add FY-wise indexing
Implement upsert logic by CIN + FY
Track source_form & filing_date
Store derived totals (assets, liabilities)
EPIC 3: Company Master Database
Goal: Single source of truth for every company.
User Story 3.1 – Company Master Profile
As a system
I want a canonical company profile
So that all modules reference the same entity
Tasks
Create company_master table
CIN-based primary key
Map ROC, category, class, status
Add incorporation & AGM dates
Add data_last_refreshed
User Story 3.2 – Director & Management Registry
As a compliance user
I want director mappings
So that governance risk is visible
Tasks
Create directors table
Create director_company_map
Track appointment & cessation
Add DIN validation
Support multi-company linkage
EPIC 4: Charges, Shareholding & Risk Data
Goal: Expose leverage, ownership, and risk indicators.
User Story 4.1 – Charges & Borrowings
As a risk analyst
I want active charge visibility
So that leverage is transparent
Tasks
Create charges table
Store charge amount & holder
Track creation & satisfaction
Calculate total secured borrowing
Flag overdue charges
User Story 4.2 – Shareholding Structure
As a wealth advisor
I want shareholding patterns
So that ownership risk is clear
Tasks
Create shareholding_pattern table
Categorize promoter / public / institutional
Store % holdings
Handle partial disclosures
Version by reporting date
EPIC 5: Analytics & Derived Metrics Engine
Goal: FintekPro-specific intelligence beyond MCA raw data.
User Story 5.1 – Financial Ratios & Trends
As a FintekPro agent
I want computed metrics
So that I can explain performance quickly
Tasks
Calculate YoY revenue & PAT growth
Compute ROE, ROA, Debt-Equity
Create derived_financial_metrics
Cache metrics per CIN + FY
Add trend direction flags
User Story 5.2 – Risk Scoring Framework
As a compliance team
I want rule-based risk scores
So that red flags are surfaced early
Tasks
Design scoring rubric (0–100)
Add profit consistency index
Add leverage risk score
Add compliance freshness score
Store final risk grade (Low/Medium/High)
EPIC 6: Probe42-Style Company Profile API
Goal: Serve instant, structured company data to UI.
User Story 6.1 – Company Profile API
As a frontend app
I want a single company endpoint
So that page load is fast
Tasks
Build GET /company/{cin}
Aggregate master + financials + directors
Add caching layer (Redis)
Include data freshness metadata
Enforce role-based redaction
User Story 6.2 – Financial History API
As a charting UI
I want FY-wise data
So that trends are visualized
Tasks
Build GET /company/{cin}/financials
Return ordered FY series
Include derived metrics
Support max-FY parameter
Optimize query indexes
EPIC 7: Frontend – Company “About” Page
Goal: Probe42-like presentation inside FintekPro.
User Story 7.1 – Company Overview Section
As a user
I want key company facts
So that I understand context immediately
Tasks
Build overview card (name, CIN, status)
Display ROC & incorporation date
Show capital structure
Add industry classification
Add last refreshed timestamp
User Story 7.2 – Financial Performance Section
As a client/agent
I want financial snapshots
So that health is obvious
Tasks
Render FY table (Revenue, PAT, Net Worth)
Add sparkline trends
Highlight negative growth
Show ratio badges
Add export to PDF
EPIC 8: Compliance, Audit & Access Control
Goal: Regulator-safe, auditable data usage.
User Story 8.1 – Audit Trail & Versioning
As a compliance officer
I want full traceability
So that inspections are smooth
Tasks
Store raw filing references
Link derived data → source form
Maintain version history
Add ingestion logs
Create audit export endpoint
User Story 8.2 – Access Control & Disclaimers
As a platform owner
I want controlled data access
So that misuse is prevented
Tasks
Role-based data masking
Add legal disclaimer banner
Restrict raw MCA downloads
Log sensitive data access
Admin override controls
EPIC 9: Monitoring & Scalability
Goal: Production-grade reliability.
Tasks
Add ETL failure alerts
Monitor ingestion latency
Add data freshness dashboard
Implement retry & rollback logic
Scale ingestion workers horizontally
