2. ISIN → Instrument Auto-Detection Rules Engine
Rule Priority (Strict Order)
1. ISIN Prefix
2. Depository Instrument Type
3. AMFI Classification (MF only)
4. Issuer Type (Bank / NBFC / Corporate)
5. Security Attributes (coupon, maturity, convertibility)
Core Detection Logic
IF prefix = INF → Mutual Fund / ETF
IF prefix = INS → Government Security
IF prefix = INV → Securitised Instrument
IF prefix = INX → Temporary Instrument (Entitlement)
IF prefix = INE → Run Deep Instrument Resolver
Deep Resolver for INE
IF issuer_type = BANK AND coupon_defined → Bank Bond / AT1 / Tier-2
IF issuer_type = NBFC AND maturity_defined → NBFC NCD
IF equity_flag = TRUE → Equity / Preference / Warrant
IF structured_payoff = TRUE → MLD
IF trust_type = REIT/InvIT → Trust Unit
3. Prefix + Metadata Validation Matrix
Validation Table: instrument_validation_rules
Prefix	Expected Instrument	Mandatory Fields	Reject If
INF	Mutual Fund	plan, option	maturity exists
INS	G-Sec / T-Bill	maturity, coupon	issuer = private
INE	Equity	equity_flag	coupon exists
INE	NCD	maturity, coupon	equity_flag = true
INV	Securitised	pool_id	issuer missing
INX	Entitlement	expiry_date	maturity exists
Hard Rules
INF + coupon → Reject
INS + AMC name → Reject
INE + both coupon & equity_flag → Flag (Convertible)
4. Complete Postgres Schema (Canonical)
4.1 Core ISIN Table
CREATE TABLE isin_master (
  isin VARCHAR(12) PRIMARY KEY,
  prefix CHAR(3),
  instrument_family VARCHAR(50),
  issuer_name TEXT,
  issuer_type VARCHAR(30),
  regulator VARCHAR(10),
  active_flag BOOLEAN,
  first_seen DATE,
  last_verified DATE
);
4.2 Instrument Attributes (Extensible)
CREATE TABLE instrument_attributes (
  isin VARCHAR(12),
  coupon NUMERIC,
  maturity_date DATE,
  face_value NUMERIC,
  convertible BOOLEAN,
  secured BOOLEAN,
  perpetual BOOLEAN,
  structured BOOLEAN,
  gold_linked BOOLEAN,
  FOREIGN KEY (isin) REFERENCES isin_master(isin)
);
4.3 Asset Taxonomy
CREATE TABLE instrument_taxonomy (
  isin VARCHAR(12),
  asset_class VARCHAR(30),
  sub_asset_class VARCHAR(50),
  instrument_type VARCHAR(50),
  FOREIGN KEY (isin) REFERENCES isin_master(isin)
);
4.4 Compliance & Regulation
CREATE TABLE instrument_compliance (
  isin VARCHAR(12),
  regulator VARCHAR(10),
  sebi_applicable BOOLEAN,
  rbi_applicable BOOLEAN,
  disclosure_regime TEXT,
  FOREIGN KEY (isin) REFERENCES isin_master(isin)
);

6. Edge-Case Handling (Mandatory)
6.1 Market Linked Debentures (MLDs)
Detection:
INE + structured = TRUE + coupon NULL
Classification:
Asset Class: Fixed Income
Sub-Class: Structured Debt
Risk Level: High
6.2 AT1 / Perpetual Bank Bonds
Detection:
INE + issuer_type = BANK + perpetual = TRUE
Rules:
No maturity
Write-down / conversion clauses
RBI governed
6.3 Sovereign Gold Bonds (SGBs)
Detection:
INS + gold_linked = TRUE
Classification:
Asset Class: Commodities
Instrument: Sovereign Gold Bond
Regulator: RBI
6.4 Convertible Instruments
Detection:
INE + coupon + equity_flag = TRUE
Classification:
Primary: Debt
Secondary: Equity-linked
