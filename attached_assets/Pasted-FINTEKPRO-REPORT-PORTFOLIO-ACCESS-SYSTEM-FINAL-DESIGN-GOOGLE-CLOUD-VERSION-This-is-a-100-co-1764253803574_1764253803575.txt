5. CLIENT UX FLOW FOR DOWNLOADING REPORTS
Client → Login → Dashboard
→ Click “Reports”
→ Choose Report Category
→ Select Date Range
→ Click “Download PDF / Excel”
→ (Optional) “Send to Email”
→ Report fetched → Stored in GCS → Served securely to user
6. ROLE-BASED ACCESS CONTROL (MANDATORY FOR SEBI)
Role	Access
Client	Only own reports
Admin	Support-level access (masked PAN, masked Aadhaar)
Compliance Officer	Full audit log & regulatory reports
Agent/Partner	Can only see clients mapped to them (NO PAN/Aadhaar visible)
System/AI	Restricted to logs, cannot access client financial documents
7. COMPLETE END-TO-END FLOW FOR REPORT GENERATION
Step-by-step Flow
User Login
   ↓
User Requests a Report (e.g., MF Holdings)
   ↓
Fintekpro queries API (BSE STAR MF / AA / CRA / EPFO / Registrar)
   ↓
Response normalized → Report generated (PDF/XLSX)
   ↓
Report saved to Google Cloud Storage (encrypted)
   ↓
Audit log written to Audit DB + GCP Cloud Audit Logs
   ↓
Frontend provides download link (tokenized & expires)
   ↓
User downloads or emails the report
8. Audit & Compliance Logging (Mandatory)
Each report generation writes entries to:
audit_logs table
Field	Description
user_id	Client
report_type	MF Transactions, Demat Snapshot, etc.
date_range	From/To
ip_address	For forensics
action	“REPORT_GENERATED”
timestamp	UTC
storage_path	GCS path
consent_reference	AA/KRA Consent ID
Full logs also stored in Google Cloud Audit Logging.
