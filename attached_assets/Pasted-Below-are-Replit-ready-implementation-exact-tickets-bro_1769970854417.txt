📌 EPIC 1: Prospect Readiness & Gating
🔧 Backend Ticket 1.1 – Prospect Readiness State Machine
Type: Backend
Priority: High
Description
Introduce a deterministic readiness state for prospects to prevent proposal generation with incomplete data.
Tasks
Add prospect_status enum:
HOLDINGS_IMPORTED
RISK_PROFILE_COMPLETED
TAX_PROFILE_COMPLETED
READY_FOR_PROPOSAL
Update prospect service to auto-advance status on:
CAS/manual holdings import
Risk questionnaire completion
Tax profile save
Block /generate-proposal if status ≠ READY_FOR_PROPOSAL
Acceptance Criteria
Proposal APIs return 400 with actionable error if prospect not ready
Status transitions are logged
🎨 Frontend Ticket 1.2 – Prospect Readiness Indicators
Type: Frontend
Description
Show readiness status clearly inside Agent Prospect Wizard.
Tasks
Display checklist UI:
Holdings ✔ / ✖
Risk Profile ✔ / ✖
Tax Profile ✔ / ✖
Disable “Generate Proposal” CTA until READY
Show warning banner explaining missing steps
Acceptance Criteria
Agent cannot bypass readiness checks
UI state mirrors backend status
