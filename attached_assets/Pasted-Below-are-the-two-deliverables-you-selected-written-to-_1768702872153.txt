PART A — Bank Product Eligibility Matrix
(Who approves what, and when to route)
Purpose: Increase approval rates and reduce bank rejections by routing only eligible profiles.
1. Personal Loan – Eligibility Matrix
Bank	Employment	Min Income	Min CIBIL	Max Tenure	Notes
ICICI Bank	Salaried	₹25k	750	72 months	Strong metro approval
HDFC Bank	Salaried	₹30k	740	60 months	Employer profiling critical
Axis Bank	Salaried / SE	₹25k	720	60 months	Flexible underwriting
Kotak Mahindra Bank	Salaried	₹20k	730	60 months	Faster TAT, lower ticket
Routing Rule (Recommended)
IF salaried AND CIBIL ≥ 750
 → ICICI → HDFC → Axis
ELSE IF salaried AND CIBIL 720–749
 → Axis → Kotak

PART B — Commission Reconciliation Automation
(Bank → Master DSA → Fintekpro)
1. Problem This Solves
Without automation:
Missed payouts
Manual Excel tracking
Disputes with Master DSA
Revenue leakage
This design gives bank-level reconciliation + audit-ready records.
2. Commission Lifecycle (System View)
Loan Disbursed
 → Commission Accrued
 → Bank Pays Master DSA
 → Master DSA Pays Fintekpro
 → Reconciliation Closed
3. Core Tables (Minimal & Sufficient)
loan_disbursement
Field	Description
loan_id	Internal ID
bank	ICICI / HDFC / Axis / Kotak
disbursed_amount	₹
disbursement_date	Date
commission_accrual
Field	Description
loan_id	FK
commission_rate	%
expected_commission	Calculated
accrual_status	pending
commission_payment
Field	Description
loan_id	FK
paid_by	Bank / Master DSA
paid_amount	₹
paid_date	Date
utr	Reference
4. Automated Reconciliation Logic
Step 1: Accrual on Disbursement
expected_commission = disbursed_amount × agreed_rate
Triggered automatically when status = DISBURSED.
Step 2: Ingest Payment Statement
Upload:
Bank payout CSV OR
Master DSA settlement file
Parse & normalize
Step 3: Match Engine
IF paid_amount == expected_commission
 → status = SETTLED
ELSE
 → status = DISPUTED
Tolerance (₹ ±100) configurable.
Step 4: Exception Dashboard
Ops sees:
Missing payouts
Partial payments
Delayed settlements (>30 days)
5. Revenue Recognition (Accounting-Ready)
Stage	Status
Accrued	Income receivable
Paid	Income realized
Disputed	Suspense
Exports cleanly to Zoho Books / Tally.
6. Compliance & Audit
Store for each commission:
Loan ID
Bank sanction letter
DSA agreement rate
Payout proof (UTR)
This is critical during:
Bank audits
Due diligence
Investor review
