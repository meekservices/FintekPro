ENABLE CLIENT & AGENT TO ADD AIF + PMS UNDER EXISTING INVESTMENTS
So that AI can calculate exposure and propose fresh investments
1. OBJECTIVE
Clients and Agents must be able to:
Add existing AIF investments
Add existing PMS investments
Edit/update these holdings
Upload supporting documents
Sync holdings with valuation engine (daily for AIF)
Allow AI to use these holdings to:
Identify gaps
Suggest fresh investments
Recommend top-ups
Flag risk or concentration issues
Compare existing vs available alternatives
This creates a complete portfolio picture similar to PMS/AIF features on sophisticated platforms like Finalyca + Private Wealth systems.
2. UPDATE EXISTING “CLIENT PORTFOLIO” MODULE
Add additional asset class categories:
Existing Investments
   ├── Equity
   ├── Mutual Funds
   ├── Bonds / MLDs
   ├── Unlisted
   ├── AIF (NEW)
   └── PMS (NEW)
Both clients and agents must be allowed to add/edit investments.
3. FRONTEND UI REQUIREMENTS
3.1 AIF – Add Existing Investment Form
Fields to capture:
Field	Description
AIF Scheme Name	Autocomplete from aif_master
Registration Number	Auto-populate from master
Commitment Amount	Required
Capital Called Till Date	Required
Units / NAV at Entry	Optional
Date of Initial Investment	Required
Lock-in End Date	Derived or manual
Latest NAV	Auto-fetched (daily/monthly)
Documents	Upload capital call letters, statements
Optional advanced fields:
Category (Cat I, II, III)
Strategy (credit / LS / multi-strategy)
Commitment structure (capital-call model)
Validation
Min investment rule (₹1 Cr or fund rule)
Fund status must be Active or Existing Investors Allowed
3.2 PMS – Add Existing Investment Form
Fields:
Field	Description
PMS Scheme Name	Autocomplete from pms_master
Registration Number	Auto-populate
Initial Investment Amount	Required
Capital Infusion Dates	Optional
Corpus Value	Optional or auto-computed
Start Date	Required
Current Value	Agent/Client can enter or auto-sync later
Upload Statements	Monthly PMS statements
Validation
Minimum investment rule: ₹50 Lakhs or fund-defined
Fund must be Active or Existing Investors Allowed

5. VALUATION ENGINE INTEGRATION
5.1 AIF
Use daily NAV (if available) or monthly NAV to compute:
current_value = units * latest_nav
If commitment-based:
current_value = capital_called * nav_multiplier
Schedule daily valuation for all AIF entries.
5.2 PMS
Use NAV equivalent provided in PMS statements or administrator feed.
If unavailable, allow manual update by agent.
6. AI ADVISOR INTEGRATION
The AI Recommendation Engine must use AIF/PMS holdings to:
6.1 Detect allocation gaps
Examples:
Client invested only in credit AIFs → AI proposes LS or hybrid AIF for diversification
PMS allocation low vs equity goals → AI suggests suitable PMS with better risk-adjusted return
6.2 Calculate overexposure / concentration
Too much credit exposure → risk alert
Too much single strategy PMS → suggest balancing strategies
Overexposure to long-short strategies → propose diversification
6.3 Evaluate performance vs alternatives
For each holding:
compare existing_fund vs similar category funds:
  - 1Y,3Y,5Y returns
  - volatility
  - manager consistency
  - drawdown
  - risk score
  - suitability for client risk profile
6.4 Proposal generation
AI should propose:
New AIF recommendations
PMS alternatives
Top-up into existing high-performing schemes
Exit suggestions for underperformers
7. DOCUMENT INGESTION
