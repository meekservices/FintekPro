FINTEKPRO — DEVELOPMENT INSTRUCTIONS
ADD “AIF” & “PMS” PRODUCT CATEGORIES UNDER STORE MENU
Inspired by Finalyca’s India-centric Institutional-Grade PMS & AIF Analytics
1. OBJECTIVE
Enhance Fintekpro by adding AIF and PMS as dedicated investment product categories under the Store Menu, with functionalities comparable to Finalyca:
Show all active PMS and AIF schemes (admin controlled)
Display institutional-grade analytics: monthwise performance, rolling returns, volatility, drawdowns, manager info
Allow clients to compare PMS/AIF schemes side-by-side
Enable AI-driven suitability & recommendation
Provide deep, historical insights similar to Finalyca

3. BACKEND — DATABASE UPDATES
Update DB with two new master tables and related analytics tables (from earlier specs):
3.1 Table: aif_master
aif_master (
  aif_id UUID PK,
  name TEXT,
  registration_no TEXT UNIQUE,
  category TEXT,
  manager_id UUID,
  sponsor TEXT,
  fund_house_name TEXT,
  style TEXT,
  min_investment NUMERIC,
  lock_in TEXT,
  liquidity_frequency TEXT,
  fund_status ENUM('active','soft_close','hard_close','existing_only','suspended'),
  is_published BOOLEAN DEFAULT FALSE,
  nav_frequency ENUM('DAILY','WEEKLY','MONTHLY'),
  last_nav_date DATE,
  isin TEXT NULL,
  metadata JSONB,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
)
is_published = TRUE means admin has approved scheme to show in STORE.
3.2 Table: pms_master
pms_master (
  pms_id UUID PK,
  name TEXT,
  registration_no TEXT UNIQUE,
  manager_id UUID,
  strategy TEXT,
  sponsor TEXT,
  min_investment NUMERIC,
  fund_status ENUM('active','soft_close','hard_close','existing_only','suspended'),
  is_published BOOLEAN DEFAULT FALSE,
  metadata JSONB,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
)
