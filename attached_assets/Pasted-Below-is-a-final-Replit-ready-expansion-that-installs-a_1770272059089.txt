1️⃣ SIP ROUTING TO REDUCE OVERLAP
BE-17: SIP Allocation Optimizer (Overlap-Aware)
Type: Backend – Analytics
Priority: P0
Description
Route SIP amounts dynamically across selected funds to minimize incremental stock overlap.
Inputs
{
  "sip_amount": 25000,
  "candidate_funds": ["INF123", "INF456", "INF789"],
  "existing_portfolio": [...]
}
Logic
For each SIP-eligible fund:
incremental_overlap =
  Σ (fund_stock_weight × existing_portfolio_stock_exposure)

score = expected_return_score − overlap_penalty
Allocate SIP proportionally to lowest overlap score first.
Output
{
  "sip_routing": [
    { "fund": "INF456", "amount": 12000 },
    { "fund": "INF789", "amount": 8000 },
    { "fund": "INF123", "amount": 5000 }
  ]
}
Acceptance Criteria
Total SIP = input amount
No fund increases top-stock exposure beyond threshold
Deterministic allocation
