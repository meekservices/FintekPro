🧩 Container Breakdown
1️⃣ API Gateway Container
Image: nginx:alpine
Responsibilities:
TLS termination
HSTS enforcement
CSP headers
Rate limiting
Proxy to internal services
Request logging
Hardening:
Only 443 exposed
HTTP → HTTPS redirect
No internal IP leakage
2️⃣ Auth Service (WebAuthn Container)
Image: node:20-alpine
Responsibilities:
WebAuthn registration & verification
Challenge generation (Redis)
JWT issuance
Sign count validation
Device binding
Step-up trigger signals
Environment isolation:
No direct DB write except credential table
Secrets via Docker secrets
3️⃣ Core API Container
Handles:
Orders
Portfolios
Proposal Builder
Unlisted asset lifecycle
SEBI categorization engine
Stateless service:
Horizontal scale safe
Uses JWT validation middleware
4️⃣ Risk Engine Container
Independent microservice.
Handles:
Behavioral scoring
Geo anomaly detection
Transaction size analysis
Device fingerprint analysis
Step-up authentication decision
This separation ensures:
Independent scaling
Audit traceability
Mathematical model isolation
5️⃣ Redis Cluster Container
Used for:
WebAuthn challenge storage
Rate limiting
Session blacklist
Event-driven queues
Async enrichment jobs
Configured:
Redis Sentinel
Persistence enabled (AOF)
6️⃣ PostgreSQL High Availability
Container Setup:
Primary DB
Read replica
WAL archiving
PITR (Point-in-time recovery)
Tables:
user_credentials
risk_events
auth_audit_logs
kyc_vault_metadata
device_registry
transaction_log
7️⃣ Object Storage Container (MinIO or S3)
Stores:
KYC documents
Immutable audit logs (WORM)
Signed transaction proofs
SEBI audit exports
Encryption:
AES-256 at rest
KMS integration
🐳 Production Docker Compose (Institutional Baseline)
version: "3.9"

services:

  nginx:
    image: nginx:alpine
    ports:
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
    depends_on:
      - auth
      - core
      - risk

  auth:
    build: ./auth-service
    environment:
      - DB_URL=postgres://...
      - REDIS_URL=redis://redis:6379
    depends_on:
      - redis
      - postgres

  core:
    build: ./core-api
    environment:
      - DB_URL=postgres://...
      - REDIS_URL=redis://redis:6379
    depends_on:
      - postgres

  risk:
    build: ./risk-engine
    environment:
      - DB_URL=postgres://...
    depends_on:
      - postgres

  redis:
    image: redis:7-alpine
    volumes:
      - redis-data:/data

  postgres:
    image: postgres:15
    volumes:
      - pg-data:/var/lib/postgresql/data

volumes:
  redis-data:
  pg-data:
⚠️ Production deployment should use Docker Swarm or Kubernetes, not plain compose.
