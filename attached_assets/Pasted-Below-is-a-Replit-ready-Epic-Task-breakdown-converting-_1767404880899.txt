Below is a Replit-ready Epic & Task breakdown converting the FintekPro Global Advisory Product Matrix into an engineering-executable roadmap.

FintekPro – Global Advisory (Non-US)
Replit Epics & Tasks
EPIC 1: Global Advisory Foundation (Platform Core)

Objective:
Enable FintekPro to support multi-country advisory without execution, while maintaining SEBI-safe positioning.

Tasks

Create GLOBAL_ADVISORY_MODE feature flag

Add Market Selector (India / Global) at session level

Implement Advisory Mode Badge:

“Full Advisory” (India)

“Analytics-Only Advisory” (Global)

Add mandatory global advisory disclaimer modal

Store client acknowledgment with timestamp & IP

Add audit log entry for every global advisory view

EPIC 2: Market & Geography Configuration Engine

Objective:
Define which products, analytics, and AI features are allowed per market.

Tasks

Create markets_master table

market_code (IN, UK, EU, SG, JP, HK, ME, EM)

advisory_level (FULL / ANALYTICS_ONLY)

currency

enabled_status

Create market_product_matrix

Build Admin UI to:

Enable/disable markets

Toggle products per market

Add backend guardrails:

Prevent execution flows outside India

Add environment-based restrictions (DEV / PROD)

EPIC 3: Product Coverage Engine (Global)

Objective:
Standardize product availability per geography.

Tasks

Create global product taxonomy:

Equity

ETF

REIT

Bond / Sukuk ETF

Tag products with:

Country

Exchange

Risk category

Add “ETF-only” restriction logic for EM & select markets

Add product visibility rules based on client risk profile

Add compliance filter for restricted instruments

EPIC 4: AI Global Asset Allocation Engine

Objective:
Deliver AI-driven global allocation while remaining advisory-only.

Tasks

Extend AI allocator to support:

Multi-currency portfolios

Country weights

Add correlation matrix (India vs Global markets)

Add country risk score input (manual + AI)

Add FX impact simulation engine

Add AI explanation layer:

Why this country

Why this allocation

Add hard stop for discretionary execution

EPIC 5: Global Model Portfolio Framework

Objective:
Offer model portfolios without execution authority.

Tasks

Create global_model_portfolios

Support portfolio types:

Conservative

Balanced

Growth

Add INR-adjusted performance view

Add currency toggle (INR / USD / EUR)

Add rebalancing signals only (no action buttons)

Store AI rationale snapshots for audit

EPIC 6: Rebalancing & Signal Governance

Objective:
Ensure signals remain advisory and non-binding.

Tasks

Implement signal classification:

Informational

Advisory

Disable “Buy / Sell” buttons for global markets

Add “Discuss with your broker” CTA

Add signal expiry & refresh logic

Log client views of rebalancing signals

EPIC 7: Client Segment Mapping

Objective:
Enable different advisory experiences by client type.

Tasks

Extend client profile:

Resident Indian

NRI

HNI / UHNI

Family Office

Map allowed markets per segment

Enable consolidated reporting for NRI & UHNI

Restrict unsuitable markets based on risk score

Add Admin override (with justification)

EPIC 8: Compliance, Disclosure & SEBI Readiness

Objective:
Make the system inspection-proof.

Tasks

Add disclosure templates per market

Force disclosure acceptance before analytics access

Add advisory classification label on every screen

Maintain immutable advisory audit trail

Generate SEBI inspection export:

Advisory views

AI rationale

Client acknowledgments

EPIC 9: Execution Partner Redirection (No Brokerage)

Objective:
Support execution without touching money or orders.

Tasks

Create partner directory (read-only)

Add “Execute with your broker” external redirect

Block deep-linking to transaction APIs

Add compliance disclaimer on redirection

Log outbound redirection events

EPIC 10: Global Reporting & Dashboards

Objective:
Deliver unified reporting across geographies.

Tasks

Multi-currency portfolio valuation engine

INR-base consolidated reporting

Country-wise allocation charts

FX contribution breakdown

Downloadable PDF reports with disclosures

Objective:

Tasks

Market enable/disable toggles

Audit review dashboard

Emergency kill-switch for global advisory
