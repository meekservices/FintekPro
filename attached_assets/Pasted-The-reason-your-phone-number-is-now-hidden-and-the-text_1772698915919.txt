The reason your phone number is now hidden and the text is overlapping is that html2canvas is struggling with line-height rendering during the export process. When you use relative units or small margins, the engine often collapses the height of the container, making the lines "crush" together at the top or bottom.

To fix this and achieve your goal of vertically centered text, we will use a "Container-Within-a-Container" approach. This forces the engine to respect a specific, fixed vertical space.

2. The Export Logic (onclone)
This script forces the engine to treat each line as a Table Row layout, which is the most stable way to prevent overlapping in html2canvas.

TypeScript
const handleExportPNG = async () => {
  const element = document.getElementById('greeting-card');
  if (!element) return;

  const canvas = await html2canvas(element, {
    useCORS: true,
    scale: 3, // High resolution
    backgroundColor: null,
    onclone: (clonedDoc) => {
      const container = clonedDoc.getElementById('agent-text-block');
      if (container) {
        // Force the container to occupy its full height
        container.style.display = 'block';
        container.style.height = '100px';
        container.style.position = 'relative';

        const name = clonedDoc.querySelector('.agent-name') as HTMLElement;
        const designation = clonedDoc.querySelector('.agent-designation') as HTMLElement;
        const contacts = clonedDoc.querySelectorAll('.agent-contact-row') as NodeListOf<HTMLElement>;

        // MANUALLY POSITION EVERY LINE TO ENSURE ZERO OVERLAP
        // This is the only way to stop the "squashing"
        if (name) {
          name.style.position = 'absolute';
          name.style.top = '0px';
          name.style.lineHeight = '20px';
        }
        if (designation) {
          designation.style.position = 'absolute';
          designation.style.top = '28px'; // Forced gap
          designation.style.color = '#FFD700';
        }
        if (contacts[0]) { // Email
          contacts[0].style.position = 'absolute';
          contacts[0].style.top = '54px';
          contacts[0].style.display = 'flex';
        }
        if (contacts[1]) { // Phone
          contacts[1].style.position = 'absolute';
          contacts[1].style.top = '74px';
          contacts[1].style.display = 'flex';
        }
      }
    }
  });

  const link = document.createElement('a');
  link.download = `diwali-greeting.png`;
  link.href = canvas.toDataURL('image/png', 1.0);
  link.click();
};
Why this fixes the "Hidden Phone Number"
Absolute Vertical Slots: By assigning the phone number to exactly top: 74px within a 100px container, it is physically impossible for it to be "pushed" out of the image or hidden by other text.

Central Alignment: Using a 100px height for the text block inside a 128px (h-32) footer automatically creates a vertically centered look.

Scale 3 Sharpness: Keeping the scale high ensures that when the browser places the text at these coordinates, it remains sharp and doesn't blur into the background.
