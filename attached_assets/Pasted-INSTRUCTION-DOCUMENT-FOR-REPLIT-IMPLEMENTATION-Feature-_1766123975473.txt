INSTRUCTION DOCUMENT FOR REPLIT IMPLEMENTATION
Feature: Admin-Driven Role-Based Commission Calibration for Fintekpro
1. Objective
Implement a complete role-based commission configuration system accessible from the Admin Portal, enabling Admin, Finance Head, and Master Agent (if permitted) to:
Create, modify, freeze, version-control, and activate commission plans
Calibrate commission percentages by role
Configure payout modes and hierarchy splits
Ensure audit logging, regulatory validation, and automatic propagation to the Commission Engine
This feature must integrate fully with Fintekpro’s hierarchy, product catalog, and transaction workflow.
2. Required Modules
Implement/update the following:
Commission Master UI (Admin Portal)
Commission Config Backend Service
Commission Engine Integration
Audit Trail Logging
RBAC Enforcement
Notification Service for Commission Change Alerts

4. Backend API Implementation Instructions
Create the following endpoints:
4.1 GET /admin/commission-plans
Return all versions for a product_type.
4.2 GET /admin/commission-plan/{id}
Return plan with role mappings and splits.
4.3 POST /admin/commission-plan
Create or update a commission plan.
Input:
{
  "product_type": "mutual_fund",
  "roles": [
    {"role_id": 3, "percentage": 50, "payout_mode": "trail"},
    {"role_id": 4, "percentage": 30, "payout_mode": "trail"},
    {"role_id": 5, "percentage": 10, "payout_mode": "trail"}
  ],
  "hierarchy_splits": [
    {"role_id": 3, "hierarchy_level": 3, "share_percentage": 50},
    {"role_id": 4, "hierarchy_level": 4, "share_percentage": 30}
  ],
  "effective_from": "2025-01-01",
  "reason": "Regulatory update"
}
4.4 POST /admin/commission-plan/{id}/activate
Deactivate previous active plan and activate new version.
4.5 POST /admin/commission-plan/{id}/freeze
Freeze all editing actions.
4.6 GET /admin/commission-plan/{id}/audit-log
Return complete modification history.
5. Commission Validation Rules (Implement in Backend)
Sum of all payout percentages must equal 100% or system computes company share automatically.
MF Direct Plans must always be 0% commission.
ARN/EUIN validation for MF distributors.
No plan can be backdated without Superadmin override.
Regulatory caps enforced during save:
MF trail maximum as per AMFI
PMS/AIF performance fee structure validated
A plan cannot be activated unless:
All payout modes assigned
Total percentage valid
Effective date >= current date
