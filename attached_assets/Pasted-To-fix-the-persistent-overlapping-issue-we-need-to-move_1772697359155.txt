2. The Export Logic (onclone)
When html2canvas clones the element, it often strips "gap" properties or collapses line-heights. This onclone function forces every element to behave as a block with a mandatory bottom margin.

TypeScript
const handleExportPNG = async () => {
  const element = document.getElementById('greeting-card');
  if (!element) return;

  const canvas = await html2canvas(element, {
    useCORS: true,
    scale: 2, // High quality export
    backgroundColor: null,
    onclone: (clonedDoc) => {
      const container = clonedDoc.getElementById('agent-text-block');
      if (container) {
        // Force the container to not collapse
        container.style.display = 'block';
        container.style.position = 'relative';
        container.style.height = 'auto';

        // Get all direct children (Name, Designation, Contact List)
        const rows = Array.from(container.children) as HTMLElement[];
        
        rows.forEach((row, index) => {
          row.style.display = 'block';
          row.style.position = 'relative';
          row.style.top = '0px'; // Reset any absolute top coordinates
          row.style.marginBottom = '8px'; // Forced physical gap
          row.style.lineHeight = '1.2';
          
          // Ensure the designation is explicitly colored Gold in the export
          if (row.classList.contains('agent-designation')) {
            row.style.color = '#FFD700';
          }
        });

        // Ensure contact rows inside the nested div also don't overlap
        const contactRows = clonedDoc.querySelectorAll('.agent-contact') as NodeListOf<HTMLElement>;
        contactRows.forEach(c => {
          c.style.display = 'flex';
          c.style.marginBottom = '4px';
        });
      }
    }
  });

  // Download logic
  const link = document.createElement('a');
  link.download = `diwali-greeting-${agent.name}.png`;
  link.href = canvas.toDataURL('image/png');
  link.click();
};
Why this version works:
Block Flow: By using display: block and marginBottom, we tell the browser "this element occupies its own space." It is physically impossible for the text to overlap because the next element starts only after the previous one's margin ends.

Resetting "Top": Your previous images failed because top: 26px was still present. This code explicitly resets top to 0px.

Color Injection: Specifically targeting #FFD700 for the designation ensures that the rendering engine doesn't default it to white/gray.
