# Initiate Session

> The Initiate Session API returns a EntityLocker link that the user is redirected to, where they can provide consent for the requested documents.

## OpenAPI

````yaml api-reference/kyc/openapi.json post /kyc/entitylocker/sessions/init
openapi: 3.1.0
info:
  title: KYC
  version: 1.0.0
  description: ''
servers:
  - url: https://api.sandbox.co.in
  - url: https://test-api.sandbox.co.in
security: []
paths:
  /kyc/entitylocker/sessions/init:
    post:
      tags:
        - EntityLocker
        - EntityLocker API
      summary: Initiate session
      parameters:
        - name: Authorization
          in: header
          required: true
          description: JWT access token
          schema:
            deprecated: false
            type: string
        - name: x-api-key
          in: header
          required: true
          description: API key for identification
          schema:
            deprecated: false
            type: string
        - name: x-api-version
          in: header
          required: false
          schema:
            type: string
      requestBody:
        content:
          application/json:
            schema:
              type: object
              properties:
                '@entity':
                  type: string
                  const: in.co.sandbox.kyc.entitylocker.session.request
                flow:
                  description: >-
                    Indicates whether the user is signing in or signing up on
                    EntityLocker
                  type: string
                  enum:
                    - signin
                    - signup
                redirect_url:
                  description: The URL to redirect the user post consent is received
                  type: string
                  format: uri
                consent_expiry:
                  description: >-
                    The expiry of the consent that the user provides. Should be
                    a minimum of 1 hour from current timestamp.
                  type: number
              required:
                - '@entity'
                - flow
                - redirect_url
            examples:
              200 Example:
                value:
                  '@entity': in.co.sandbox.kyc.entitylocker.session.request
                  flow: signin
                  redirect_url: https://sandbox.co.in
      responses:
        '200':
          description: 200 - Session initiated
          content:
            application/json:
              schema:
                type: object
                properties:
                  code:
                    type: integer
                  timestamp:
                    type: integer
                  data:
                    type: object
                    properties:
                      '@entity':
                        type: string
                      authorization_url:
                        type: string
                        format: uri
                      session_id:
                        type: string
                  transaction_id:
                    type: string
              example:
                code: 200
                timestamp: 1765534184274
                data:
                  '@entity': in.co.sandbox.kyc.entitylocker.session.response
````
